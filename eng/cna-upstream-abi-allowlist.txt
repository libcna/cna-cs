# Reviewed upstream ABI differences, accepted by tools/coverage/baselinediff.py.
#
# An entry here is a difference someone looked at and decided this consumer does not care about.
# It is not a way to quieten the tool: every entry must match an actual difference, and one that
# stops matching fails the gate as stale rather than being ignored. An entry containing `*` is a
# glob over one reviewed family and is held to the same rule.
#
# The file is scoped to the transition currently being admitted -- the accepted generation in
# eng/cna-native-abi-policy.json against the one proposed to replace it -- because a finding is a
# statement about one step and matches nothing in the next.
#
# 2026-10-01, ABI 0.21.0 (CNA 599d14e54) -> 0.35.0 (CNA bdf239360), CAMPAIGN.md CSX-010..014.
# Over the consumed surface the step is clean once this binding dropped its 44 engine-layer imports
# and `cna_graphics_ext_is_available`: 957 consumed exports, 0 absent, 0 changed prototype. What
# remains is upstream removing things this binding never imported or mirrored:
#
#   * ABI 0.30.0 (MOD-RETIRE-1) removed engine_layer.h -- pipelines, post-process passes, clustered
#     lighting, shadows, probes, optional PBR materials, particles, sky, compute -- with their
#     handles, enums and value layouts;
#   * the retired renderer identities (CNA_GRAPHICS_RENDERER_*); this binding reads the renderer's
#     name and binds no identity;
#   * the avatar "real rendering" EXT routes and the field CNA_AvatarRendererInfo carried for them;
#     this binding does not yet bind avatars at all;
#   * SpriteBatch's 2D mesh route (0.29.0).
#
# A removed export that *was* consumed would appear as "consumed export ... is absent", which no
# entry below matches. A removed or changed struct, scalar or constant that the managed side mirrors
# is measured independently by tools/abi-verify (895 layout values, 350 constants, all matching on
# 0.35.0), so these globs cannot hide a consumed layout.
